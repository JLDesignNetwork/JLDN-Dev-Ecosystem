# JLDN Dev Ecosystem

Welcome to the **JLDN Dev Ecosystem** repository. This is the centralized monorepo and single source of truth for all JLDN project protocols, scaffolding rules, and Git/Backlog governance.

## Architecture

This repository uses an **Agentic Hub-and-Spoke** architecture to orchestrate documentation across multiple JLDN ecosystem components. 

- **Backlog Schema:** Defines the task and workflow tracking standard.
- **Generational Versioning Schema (GVS):** Defines the versioning and epoch rules.
- **Project Governance:** Defines Project Creation, Git rules, and JLDN Frontmatter Metadata.
